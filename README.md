# 影视收藏馆

个人影视资料库 —— 把看过的电影、电视剧、综艺、纪录片整理、分类、展示出来。
**不是在线播放站**,只做信息管理和收藏陈列。

纯静态三页,零依赖、零外链,双击 `index.html` 就能打开,断网照常用。

```
影视收藏馆/
├── index.html          首页:头图 · 热门 · 最新添加 · 分类入口 · 高分收藏
├── list.html           片库:分类 / 类型 / 年份 / 地区筛选 + 搜索 + 排序
├── detail.html         详情:?id=liang-jian 这样带参数进来,一个模板渲染所有影片
├── assets/
│   ├── css/style.css   全站样式
│   └── js/
│       ├── data.js     ← 影视数据都在这儿,加片子只改这一个文件
│       └── app.js      三个页面共用的交互逻辑
└── data/
    ├── webflow-cms.md  Webflow CMS 集合「影视库」的字段定义与导入说明
    ├── 影视库.csv       从 data.js 导出的 52 条记录,可直接导入 CMS
    └── export-csv.js   重新导出:node data/export-csv.js
```

## 加一部片子

打开 `assets/js/data.js`,复制一条改内容,首页、片库、详情页会自动跟着变:

```js
{
  id: 'liang-jian',            // 详情页地址是 detail.html?id=liang-jian,只用小写字母数字和短横线
  title: '亮剑',
  category: '电视剧',           // 电影 / 电视剧 / 综艺 / 纪录片
  genres: ['战争', '历史'],     // 第一个是主类型
  year: 2005,
  region: '中国',
  actors: ['李幼斌', '何政军'],
  director: '陈健 / 张前',
  rating: 9.5,                 // 可留空
  description: '……',
  resource: '',                // 资源入口链接,留空则详情页按钮置灰
  added: '2025-01-08',         // 「最新添加」按它倒序
  hot: true                    // 打开会进首页「热门影视」
}
```

分类下有哪些类型标签,在 `assets/js/app.js` 顶部的 `CATEGORIES` 里改:

| 分类 | 类型标签 |
|---|---|
| 电影 | 恐怖 · 喜剧 · 动作 · 科幻 · 爱情 |
| 电视剧 | 战争 · 古装 · 悬疑 · 都市 |
| 综艺 | 真人秀 · 音乐 · 脱口秀 |
| 纪录片 | 历史 · 自然 · 科技 |

数据里出现的其它标签(犯罪、人文、治愈……)也会自动出现在筛选栏里,不用登记。

## 关于海报

`poster` 字段填图片地址就用真图;**留空则按片名算一个固定色相,生成一张配色海报** ——
同一部片子在任何页面、任何时候颜色都一样,不会闪来闪去。
所以一条记录都不配图,整站看起来也是齐整的。

## 交互

- 顶栏搜索:输入即出联想(片名 / 演员 / 类型 / 地区都能搜),↑↓ 选、回车进片库
- 片库页的搜索框直接过滤当前列表,不跳页
- 筛选条件写进地址栏 —— `list.html?category=电视剧&genre=战争` 这样的链接可以直接分享
- 鼠标悬停海报:浮出年份、地区、类型和简介摘要
- 点卡片进详情页,详情页底部按类型重合度推荐同类影片

## 搬进 CMS

要托管到 Webflow 的话,`data/webflow-cms.md` 里有集合「影视库」的完整字段表,
`data/影视库.csv` 可以直接导入。本站本身不依赖 CMS。
