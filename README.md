# 影视收藏馆

个人影视资料库 —— 把看过的电影、电视剧、综艺、纪录片整理、分类、展示出来。
**不是在线播放站**,只做信息管理和收藏陈列。

**开箱是空的。** 你加一条,站上就出现一条;一条没加,首页就是一句「馆里还是空的」加一个录入台入口。

纯静态三页,零依赖、零外链,双击 `index.html` 就能打开,断网照常用。

```
影视收藏馆/
├── index.html          首页:头图 · 热门 · 最新添加 · 分类入口 · 高分收藏
├── list.html           片库:分类 / 类型 / 年份 / 地区筛选 + 搜索 + 排序
├── detail.html         详情:?id=片名 这样带参数进来,一个模板渲染所有影片
├── admin.html          录入台:填链接 / 加片子 / 换海报,生成新的 data.js(本地工具,不对外)
├── assets/
│   ├── css/style.css   全站样式
│   └── js/
│       ├── log.js      运行日志:抓报错、记关键操作
│       ├── panels.js   站内两个小模块:填网盘链接 / 看运行日志(右下角按钮)
│       ├── poster.js   海报上传与压缩,详情页和录入台共用
│       ├── site.js     ← 站名、馆主署名、首页开场白,改文案只动这个文件
│       ├── data.js     ← 影视数据都在这儿,加片子只改这一个文件
│       ├── app.js      三个页面共用的交互逻辑
│       └── admin.js    录入台的逻辑
├── tools/
│   └── 打包单文件.py    把整站打包成一个 HTML 文件,方便存手机里离线看
└── data/
    ├── webflow-cms.md  Webflow CMS 集合「影视库」的字段定义与导入说明
    └── export-csv.js   导出 CMS 用的 CSV:node data/export-csv.js
```

## 加一部片子

打开 `assets/js/data.js`,复制一条改内容,首页、片库、详情页会自动跟着变:

```js
{
  id: '片名',                   // 详情页地址是 detail.html?id=片名,中文可以直接用,别重复
  title: '片名',
  category: '电视剧',           // 电影 / 电视剧 / 综艺 / 纪录片
  genres: ['类型一', '类型二'],  // 第一个是主类型
  year: 2005,
  region: '中国',
  actors: ['演员一', '演员二'],
  director: '导演名字',
  rating: 9.5,                 // 可留空
  description: '一段简介……',
  resource: '',                // 资源入口链接,留空则详情页按钮置灰
  resourceNote: '',            // 提取码之类,显示在资源按钮下面(可选)
  added: '2026-09-10',         // 「新近接入」按它倒序
  hot: true                    // 打开会进首页「热门影视」
}
```

分类下有哪些类型标签,在 `assets/js/app.js` 顶部的 `CATEGORIES` 里改:

| 分类 | 类型标签 |
|---|---|
| 电影 | 恐怖 · 喜剧 · 动作 · 科幻 · 爱情 |
| 电视剧 | 战争 · 古装 · 悬疑 · 都市 |
| 综艺 | 真人秀 · 音乐 · 脱口秀 |
| 纪录片 | 历史 · 自然 · 科技 |

数据里出现的其它标签(犯罪、人文、治愈……)也会自动出现在筛选栏里,不用登记。

## 视觉:局域网底子

馆主叫「乌海局域网」,整站就照着机房和内网来定调:

| 元素 | 做法 |
|---|---|
| 底色 | 机房墨绿 `#070b0d`,不是纯黑 |
| 主色 | `--accent` 是**链路灯绿** `#29c97e`(通了),`--gold` 是**活动灯琥珀** `#f0b44a`(在传),`--alert` 红退为告警色 |
| 标记 | Logo 和浏览器图标是**节点拓扑**:一个主节点挂三个终端 |
| 头图 | canvas 画的**节点连线图** —— 22 个节点缓慢漂移,偶尔有个琥珀色数据包沿链路跑过去 |
| 署名旁 | 一颗**链路灯**,3.2 秒眨一次 |
| 分区标题 | 前面那道竖条是上绿下琥珀的**指示灯**配色 |
| 用词 | 收录 → **接入**,最新添加 → **新近接入**,首页统计叫「在线影视」 |
| 详情页 | 多一行**内网地址** `192.168.1.2` —— 按接入先后算,不是编的,满 254 条自动进下一段 |

改配色在 `assets/css/style.css` 顶部的 `:root`,都是变量。
不想要节点连线图,删掉 `index.html` 里那行 `<canvas id="hero-net">` 即可,
动画本身在系统开启「减少动态效果」时会自动停成静帧。

## 改成你自己的样子

名字和文案都在 `assets/js/site.js`,改完刷新就变,不用动 HTML:

```js
window.SITE = {
  owner: '乌海局域网',                    // 顶栏署名、页脚「馆主 · ⋯」
  short: '影视收藏馆',                 // 顶栏站名
  full:  '乌海局域网的影视收藏馆',          // 浏览器标签页标题

  kicker: '乌海局域网的私人片库',          // 首页大字上面那个小胶囊
  line1:  '看过的好片',                // 首页大字第一行
  line2:  '都收在这儿',                // 第二行(金色那行)
  intro:  '这是我自己的片库。⋯',       // 大字下面那段
  footerNote: '个人影视资料库 · ⋯'      // 页脚说明
};
```

首页那段开场白是我按「乌海局域网」写的初稿,**换成你自己的话**就行 —— 它是整个站里最像你的地方。

## 空的时候什么样

一条都没有时,首页只留头图和「打开录入台」,片库是一句「还没有收录任何影视」——
不会露出空的分类格子或空的筛选栏。

加进去之后是**按需长出来的**:

- 加了第一条 → 首页出现「最新添加」和「分类浏览」(只列出真的有片子的分类)
- 某条勾了「热门」→ 首页才会出现「热门影视」这一区
- 某条填了评分 → 才会出现「高分收藏」这一区
- 年份、地区筛选项也是从你的数据里长出来的,只有一部 2005 年的片,年份档就只有「2000 年代」

## 录入台:怎么快速把链接填进去

直接改 `data.js` 也行,但填链接用 **`admin.html`** 更快 —— 双击打开就是。

### 一次补一堆链接(最常用)

打开录入台 → 右边「批量粘贴」→ 一行一部,粘完点「解析并写入」:

```
片名 | 网盘地址 | 提取码
片名 | 网盘地址
片名 | 分类 | 年份 | 地区 | 类型 | 网盘地址 | 提取码
```

**片名对得上已有条目,就只补链接,不动其它信息**;对不上才新建一条。
所以你攒了一批网盘链接,整段贴进去就完事了。分隔符 `|` 前后有没有空格都行,中文竖线和 Tab 也认。

### 一部一部细填

左边表单:片名、分类、类型标签(点选,也能回车加新标签)、年份、地区、演员、简介、
链接、提取码、评分,还能勾「放进首页热门」。
点右边列表里的任意一条,就把它读进表单里改。

列表会标出**缺链接**和**缺简介**的条目,勾上「只看缺链接的」就是一份待办清单。

### 海报怎么来

**最省事的办法:在详情页直接拖一张图到海报上。** 会自动按 EXIF 摆正、缩到 480×720
以内、从 0.82 画质往下试到体积落进 70 KB,然后立刻换上。同样是先存本地,
去录入台「并入草稿」再导出才落盘。

在录入台里也可以,三种填法:

1. **拖进去 / 选文件 / Ctrl+V 粘贴截图** —— 图片会被压到 400×600 以内转成 base64 存进 `data.js`,
   不依赖外链,断网也显示。一张约 30–60 KB
2. **粘贴图片地址** —— 注意豆瓣的图片有防盗链,直接贴它的地址多半显示不出来,
   建议存到本地再拖进来,或者放进 `assets/posters/` 后填 `assets/posters/xxx.jpg`
3. **留空** —— 用自动生成的

### 简介怎么来

目前是手填:从豆瓣、维基百科复制一段贴进简介框。录入台不联网、不抓取。

### 存盘

录入台的改动先存在浏览器 localStorage 里(关掉页面还在),
**点右上角「复制 data.js」→ 粘贴覆盖 `assets/js/data.js`,才算真正存下来。**
下载按钮也行,但在某些内嵌环境里网页发起的下载会被拦,剪贴板更可靠。

`丢弃草稿` 是回到 `data.js` 文件里的内容,改错了可以用它退回去。

## 关于海报

`poster` 字段填图片地址(或 base64)就用真图;**留空则按片名算一个固定色相,生成一张配色海报** ——
同一部片子在任何页面、任何时候颜色都一样,不会闪来闪去。
所以一条记录都不配图,整站看起来也是齐整的。

## 交互

- 顶栏搜索:输入即出联想(片名 / 演员 / 类型 / 地区都能搜),↑↓ 选、回车进片库
- 片库页的搜索框直接过滤当前列表,不跳页
- 筛选条件写进地址栏 —— `list.html?category=电视剧&genre=战争` 这样的链接可以直接分享
- 鼠标悬停海报:浮出年份、地区、类型和简介摘要
- 点卡片进详情页,详情页底部按类型重合度推荐同类影片

## 打包成单文件存手机

```bash
python3 tools/打包单文件.py              # 生成 影视收藏馆-单文件版.html
```

CSS、数据、脚本全部内联,三个页面靠 `#/`、`#/list`、`#/detail?id=` 切换,
没有外链、不联网。传到手机上双击就能开,断网照常看。

录入台不在单文件版里 —— 它要写文件,单文件版只用来看。

## 站上的两个小模块

对外三个页面的**右下角**常驻两个按钮,点开即用,不用切到录入台。

### 🔗 链接 —— 填网盘地址

**它怎么知道是哪部片子?** 三条路,按顺序来:

1. **在详情页打开** —— 就是当前这部,不用猜
2. **从分享文本里认文件名** —— 网盘那段的头一行通常是
   `通过网盘分享的文件:亮剑.2005.1080P.国语中字.mkv`,它会洗掉画质、字幕、
   集数、年份这些噪音,拿「亮剑」去片库里比对
3. **认不出就问你** —— 弹一个下拉让你挑;库里要是压根没有这部,
   直接提议「**新建《漫长的季节》**」,存完片库里立刻就多一部
   (标着「刚在站上新建的」),等你去录入台并入时会补成正式条目

所以你**只复制链接**也能用 —— 只是得自己挑一下是哪部;
连文件名一起复制的话,多数情况它自己就认出来了。


**在详情页打开**,顶上直接就是当前这部片子。从网盘复制的一整段原样粘进去:

```
通过网盘分享的文件:xxx
链接: https://pan.xxx.com/s/xxxxxx 提取码: xxxx
复制这段内容打开网盘 App
```

它自己把**地址和提取码抠出来**,你不用手动拆。识别范围:

- 带协议的和不带的(裸域名会自动补 `https://`)
- 藏在地址里的 `?pwd=abcd`
- 「提取码 / 密码 / 访问码 / pwd」后面跟的码,中英文冒号都认

**在别的页面打开**是批量框,一行一部:`片名 | 链接 | 提取码`。
认不出的行会留在框里,后面标着原因(「库里没有这部」「没认出链接」)。

填完**站上立刻生效** —— 详情页的资源按钮马上亮起来,下面标一句「这条链接还没写进 data.js」。
真要落盘,去录入台点「并入草稿」再导出。

### 📋 日志 —— 就地看运行记录

页面一出错,这个按钮上会挂个**红点**。点开能筛「只看错误」、一键复制全部。
内容和录入台底部那份是同一份。

---

这两个模块填的东西都**先存在浏览器本地**,站上马上能看到,但还没进 `data.js`。
录入台会多出一块「**待并入的内容**」,列出所有本地填的链接和海报,
点一次「并入草稿」全部写进条目,再导出就落盘了。

## 出问题了怎么查

站里带一份**运行日志**,在录入台(`admin.html`)最底下。

它会自动记下:

- 页面上的 JS 报错(带文件名和行号)
- `data.js` 读取失败 —— 这条最有用,直接告诉你第几行第几列写错了
- 存盘失败(海报图太多超出浏览器配额)
- 每次开页、读了多少条数据
- 缺字段的条目(比如「第 3 条『xxx』缺 genres, year」)
- 资源链接被判为无效地址
- 你在录入台里的增删改、批量粘贴结果、导出

页面一旦出错,左下角会冒出一个红色的「**出错了 · 看日志**」角标,点它直达。

日志只存在这台设备的浏览器里,最多留 300 条,**不联网、不上传**。
搞不定的时候点「**复制全部**」,粘出来的文本带浏览器、屏幕尺寸、打开方式这些环境信息,
直接发给别人就能排。「清空」只清日志,不动你的片子。

## 搬进 CMS

要托管到 Webflow 的话,`data/webflow-cms.md` 里有集合「影视库」的完整字段表。
跑 `node data/export-csv.js` 会把当前 `data.js` 导成 `data/影视库.csv`,直接 Import 即可。
本站本身不依赖 CMS。
