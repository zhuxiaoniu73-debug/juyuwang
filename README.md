# 影视收藏馆

个人影视资料库 —— 把看过的电影、电视剧、综艺、纪录片整理、分类、展示出来。
**不是在线播放站**,只做信息管理和收藏陈列。

**开箱是空的。** 你加一条,站上就出现一条;一条没加,首页就是一句「馆里还是空的」加一个录入台入口。

纯静态三页,零依赖、零外链,双击 `index.html` 就能打开,断网照常用。

```
影视收藏馆/
├── index.html          首页:头图 · 热门 · 最新添加 · 分类入口 · 高分收藏
├── list.html           片库:分类 / 类型 / 年份 / 地区筛选 + 搜索 + 排序
├── detail.html         详情:?id=liang-jian 这样带参数进来,一个模板渲染所有影片
├── admin.html          录入台:填链接 / 加片子 / 换海报,生成新的 data.js(本地工具,不对外)
├── assets/
│   ├── css/style.css   全站样式
│   └── js/
│       ├── site.js     ← 站名、馆主署名、首页开场白,改文案只动这个文件
│       ├── data.js     ← 影视数据都在这儿,加片子只改这一个文件
│       ├── app.js      三个页面共用的交互逻辑
│       └── admin.js    录入台的逻辑
├── tools/
│   └── 打包单文件.py    把整站打包成一个 HTML 文件,方便存手机里离线看
└── data/
    ├── webflow-cms.md  Webflow CMS 集合「影视库」的字段定义与导入说明
    ├── 示例数据.js      52 条样本,只有录入台会用到,删掉不影响任何功能
    └── export-csv.js   导出 CMS 用的 CSV:node data/export-csv.js
```

## 加一部片子

打开 `assets/js/data.js`,复制一条改内容,首页、片库、详情页会自动跟着变:

```js
{
  id: 'liang-jian',            // 详情页地址是 detail.html?id=liang-jian,只用小写字母数字和短横线
  title: '亮剑',
  category: '电视剧',           // 电影 / 电视剧 / 综艺 / 纪录片
  genres: ['战争', '历史'],     // 第一个是主类型
  year: 2005,
  region: '中国',
  actors: ['李幼斌', '何政军'],
  director: '陈健 / 张前',
  rating: 9.5,                 // 可留空
  description: '……',
  resource: '',                // 资源入口链接,留空则详情页按钮置灰
  resourceNote: '',            // 提取码之类,显示在资源按钮下面(可选)
  added: '2025-01-08',         // 「最新添加」按它倒序
  hot: true                    // 打开会进首页「热门影视」
}
```

分类下有哪些类型标签,在 `assets/js/app.js` 顶部的 `CATEGORIES` 里改:

| 分类 | 类型标签 |
|---|---|
| 电影 | 恐怖 · 喜剧 · 动作 · 科幻 · 爱情 |
| 电视剧 | 战争 · 古装 · 悬疑 · 都市 |
| 综艺 | 真人秀 · 音乐 · 脱口秀 |
| 纪录片 | 历史 · 自然 · 科技 |

数据里出现的其它标签(犯罪、人文、治愈……)也会自动出现在筛选栏里,不用登记。

## 改成你自己的样子

名字和文案都在 `assets/js/site.js`,改完刷新就变,不用动 HTML:

```js
window.SITE = {
  owner: '乌海舰',                    // 顶栏署名、页脚「馆主 · ⋯」
  short: '影视收藏馆',                 // 顶栏站名
  full:  '乌海舰的影视收藏馆',          // 浏览器标签页标题

  kicker: '乌海舰的私人片库',          // 首页大字上面那个小胶囊
  line1:  '看过的好片',                // 首页大字第一行
  line2:  '都收在这儿',                // 第二行(金色那行)
  intro:  '这是我自己的片库。⋯',       // 大字下面那段
  footerNote: '个人影视资料库 · ⋯'      // 页脚说明
};
```

首页那段开场白是我按「乌海舰」写的初稿,**换成你自己的话**就行 —— 它是整个站里最像你的地方。

## 空的时候什么样

一条都没有时,首页只留头图和「打开录入台」,片库是一句「还没有收录任何影视」——
不会露出空的分类格子或空的筛选栏。

加进去之后是**按需长出来的**:

- 加了第一条 → 首页出现「最新添加」和「分类浏览」(只列出真的有片子的分类)
- 某条勾了「热门」→ 首页才会出现「热门影视」这一区
- 某条填了评分 → 才会出现「高分收藏」这一区
- 年份、地区筛选项也是从你的数据里长出来的,只有一部 2005 年的片,年份档就只有「2000 年代」

想看看填满之后长什么样:录入台右上角「载入示例」会把 `data/示例数据.js` 里的 52 条灌进草稿,
看完点「丢弃草稿」退回自己的数据。

## 录入台:怎么快速把链接填进去

直接改 `data.js` 也行,但填链接用 **`admin.html`** 更快 —— 双击打开就是。

### 一次补一堆链接(最常用)

打开录入台 → 右边「批量粘贴」→ 一行一部,粘完点「解析并写入」:

```
亮剑 | https://pan.quark.cn/s/abc123 | 提取码 8k2p
潜伏 | https://pan.baidu.com/s/xyz789
繁花 | 电视剧 | 2023 | 中国 | 都市/年代 | https://pan.quark.cn/s/def456
```

**片名对得上已有条目,就只补链接,不动其它信息**;对不上才新建一条。
所以你攒了一批网盘链接,整段贴进去就完事了。分隔符 `|` 前后有没有空格都行,中文竖线和 Tab 也认。

### 一部一部细填

左边表单:片名、分类、类型标签(点选,也能回车加新标签)、年份、地区、演员、简介、
链接、提取码、评分,还能勾「放进首页热门」。
点右边列表里的任意一条,就把它读进表单里改。

列表会标出**缺链接**和**缺简介**的条目,勾上「只看缺链接的」就是一份待办清单。

### 海报怎么来

海报字段留空 → 自动生成配色海报,所以**不填也不难看**。想换成真海报,三种填法:

1. **拖进去 / 选文件 / Ctrl+V 粘贴截图** —— 图片会被压到 400×600 以内转成 base64 存进 `data.js`,
   不依赖外链,断网也显示。一张约 30–60 KB
2. **粘贴图片地址** —— 注意豆瓣的图片有防盗链,直接贴它的地址多半显示不出来,
   建议存到本地再拖进来,或者放进 `assets/posters/` 后填 `assets/posters/xxx.jpg`
3. **留空** —— 用自动生成的

### 简介怎么来

目前是手填:从豆瓣、维基百科复制一段贴进简介框。录入台不联网、不抓取。

### 存盘

录入台的改动先存在浏览器 localStorage 里(关掉页面还在),
**点右上角「复制 data.js」→ 粘贴覆盖 `assets/js/data.js`,才算真正存下来。**
下载按钮也行,但在某些内嵌环境里网页发起的下载会被拦,剪贴板更可靠。

`丢弃草稿` 是回到 `data.js` 文件里的内容,改错了可以用它退回去。

## 关于海报

`poster` 字段填图片地址(或 base64)就用真图;**留空则按片名算一个固定色相,生成一张配色海报** ——
同一部片子在任何页面、任何时候颜色都一样,不会闪来闪去。
所以一条记录都不配图,整站看起来也是齐整的。

## 交互

- 顶栏搜索:输入即出联想(片名 / 演员 / 类型 / 地区都能搜),↑↓ 选、回车进片库
- 片库页的搜索框直接过滤当前列表,不跳页
- 筛选条件写进地址栏 —— `list.html?category=电视剧&genre=战争` 这样的链接可以直接分享
- 鼠标悬停海报:浮出年份、地区、类型和简介摘要
- 点卡片进详情页,详情页底部按类型重合度推荐同类影片

## 打包成单文件存手机

```bash
python3 tools/打包单文件.py              # 用你自己的数据,生成 影视收藏馆-单文件版.html
python3 tools/打包单文件.py --sample     # 用示例数据,做演示用
```

CSS、数据、脚本全部内联,三个页面靠 `#/`、`#/list`、`#/detail?id=` 切换,
没有外链、不联网。传到手机上双击就能开,断网照常看。

录入台不在单文件版里 —— 它要写文件,单文件版只用来看。

## 搬进 CMS

要托管到 Webflow 的话,`data/webflow-cms.md` 里有集合「影视库」的完整字段表。
跑 `node data/export-csv.js` 会把当前 `data.js` 导成 `data/影视库.csv`,直接 Import 即可。
本站本身不依赖 CMS。
